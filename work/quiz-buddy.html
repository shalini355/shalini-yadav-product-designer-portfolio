Quiz Buddy · Learning

A programming practice platform.

Quiz Buddy lets learners practise programming across multiple languages and difficulty levels. I worked on it as part of a team.

Overview

Role
UI designer and frontend developer · Team project
Tools
HTML, CSS, JavaScript, Git

The problem

Practice across languages and skill levels.

Quiz Buddy brings programming questions together across multiple languages, with Beginner, Intermediate, and Advanced levels.

Who it's for

People practising programming.

The platform is for learners who want to practise different programming languages at a level that suits them.

What I made

A responsive practice flow.

  • Multiple programming languages
  • Beginner, Intermediate, Advanced
  • Responsive layouts
  • Dynamic question navigation
  • Score tracking

Design decisions

A few choices shape the practice experience.

Language choices

I included multiple programming languages so learners can practise in the language they want to use.

Three levels

Beginner, Intermediate, and Advanced levels let learners choose the difficulty for their practice.

Question navigation

Dynamic question navigation gives learners a way to move through the practice questions.

Responsive layouts and scores

I included responsive layouts and score tracking so the practice flow works across screen sizes and keeps a record of the score.

What I learned

I enjoy making products easy and kind to use.

Working on Quiz Buddy reinforced what I learned from building Kai: the part I love most is making a product feel easy and kind to use.
