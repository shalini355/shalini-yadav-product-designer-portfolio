Quiz Buddy

A programming practice platform with multiple languages and difficulty levels.

View Live Project View on GitHub Back to Case Studies

Project details

Role
UI designer and frontend developer · Team
Tools
HTML, CSS, JavaScript, Git

Overview

A programming practice platform.

Quiz Buddy brings together multiple programming languages, three difficulty levels, responsive layouts, dynamic question navigation, and score tracking. I worked on it as part of a team.

The Problem

Practice across languages and skill levels.

Quiz Buddy brings programming practice together across multiple languages and Beginner, Intermediate, and Advanced levels.

Who It's For

For people practising programming.

The platform is for learners who want to practise different programming languages at a level that suits them.

What I Made

A responsive practice flow.

  • Multiple programming languages
  • Beginner, Intermediate, Advanced
  • Responsive layouts
  • Dynamic question navigation
  • Score tracking

Design Decisions

A few choices shape the practice experience.

Language choices

Multiple programming languages let learners choose what they want to practise.

Three levels

Beginner, Intermediate, and Advanced levels offer three difficulty choices for practice.

Question navigation

Dynamic question navigation lets learners move through the questions.

Responsive layouts and scores

Responsive layouts support the practice flow across screen sizes, while score tracking records a learner's score.

What I Learned

I enjoy making products easy and kind to use.

Working on Quiz Buddy reinforced what I learned from building Kai: the part I love most is making a product feel easy and kind to use.
